# Карточки товара

Статический HTML-шаблон каталога продуктов с адаптивной сеткой и тёмным интерфейсом.

## Функционал

- **Каталог товаров** — сетка карточек с фото, названием, описанием
- **Информация о цене** — отображение цены с символом рубля
- **CTA кнопка** — "Купить" для каждого товара
- **Адаптивный макет** — flexbox-сетка с мобильной поддержкой
- **Перелинковка** — клик на карточку открывает ссылку товара

## Технологический стек

- **HTML5** — семантическая разметка
- **CSS3** — Flexbox, адаптивность, скруглённые углы
- **Шрифты** — Inter (Regular, SemiBold, Bold) в формате WOFF2
- **Дизайн** — тёмная тема (чёрно-серый палитра)

## Структура

```
├── index.html          # Главная страница с каталогом
├── css/
│   └── style.css       # Стили (сетка, карточки, типография)
├── img/
│   ├── NovaX.png       # Смартфон
│   ├── SonicPro.png    # Наушники
│   └── PulseWatch.png  # Смарт-часы
├── fonts/              # Шрифты Inter
├── verstaem.json       # Конфиг проекта
└── README.md           # Документация
```

## Использование

1. Откройте `index.html` в браузере
2. Сетка товаров отобразится в адаптивной теме

## Кастомизация

- Отредактируйте HTML для добавления/удаления товаров
- Измените цены в `product__price`
- Обновите ссылки в атрибутах `href`
- Замените изображения в папке `img/`
- Отрегулируйте цвета и отступы в `css/style.css`
